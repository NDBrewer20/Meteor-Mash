# Description:
A small game about avoiding Asteroids as you pilot a ship through deep space. 
## Controls:
### Gameplay:
#### Gamepad

Left Joystick - Movement\

Right Joystick - Look around\

Bottom Button (A) - Dash\

Right Trigger - Fire weapon\

Start - Pause Menu
#### Keyboard and Mouse

WASD - player movement\

Shift - Dash\

Left Mouse Button - Fire Weapon\

Escape - Pause menu
